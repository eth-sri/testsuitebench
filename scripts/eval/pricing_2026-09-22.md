# Agent run pricing estimates, 2026-09-22

[`pricing_2026-09-22.json`](pricing_2026-09-22.json) gives USD rates per million tokens for current model IDs and historical run IDs. Use it with `summarize_agent_runs.py --histograms DIR --pricing-file scripts/eval/pricing_2026-09-22.json ROOT`.

| Models | Source | Rate choice |
| --- | --- | --- |
| `gpt-5.6-luna`, `gpt-5.6-sol`, `gpt-6-astra` | [OpenAI API pricing](https://developers.openai.com/api/docs/pricing) | Standard processing, short context. |

| `deepseek/deepseek-v4-flash` | [OpenRouter 0423 pricing](https://openrouter.ai/deepseek/deepseek-v4-flash) | Historical runs. |
| `deepseek/deepseek-v4-flash-0731` | [OpenRouter 0731 pricing](https://openrouter.ai/deepseek/deepseek-v4-flash-0731) | OpenInference displayed rates; actual routed provider may differ. |
| `z-ai/glm-5.3-flash` | [OpenRouter model pricing](https://openrouter.ai/z-ai/glm-5.3-flash) | Lowest displayed, discounted provider rates. |

The plots estimate token charges, not invoice totals. The run table does not record the OpenRouter provider chosen per request, OpenAI service tier or context tier, Anthropic cache-write tokens, or Google cache storage and tool charges. Rates can change, especially OpenRouter discounts. If those details matter, compare against provider billing exports.
